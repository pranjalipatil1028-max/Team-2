# Team-2College Event Management System – Feature Set IV
Project Description
The College Event Management System is designed to manage the basic information and activities related to college events. It helps maintain participant details, event details, registration information, attendance status, and certificate status.
Features
Participant Details – Stores participant information such as Participant ID, Name, Contact, and other basic details.
Event Details – Stores Event ID, Event Name, Event Date, and Venue.
Registration – Records participant registration for a selected event.
Attendance Status – Records whether the participant is Present or Absent.
Certificate Status – Checks and records whether the participant is eligible for/has received a certificate.
Project Components
Algorithm – Describes the system process step by step.
Flowchart – Represents the process using standard flowchart symbols.
ER Diagram – Represents entities, attributes, and relationships using standard ER symbols.
Tools Used
ArchGPT for creating the Flowchart and ER Diagram.
Text/Document Editor for preparing the algorithm and README.
Objective
The main objective is to provide a simple and organized representation of a College Event Management System that is easy to understand and suitable for a 1st-semester programming practical assignment.
Expected Result
The system should successfully represent participant registration, event information, attendance tracking, and certificate status in a clear and systematic manner.
Conclusion
The College Event Management System provides a basic structure for managing college event information. The algorithm, flowchart, and ER diagram together give a clear understanding of the system's working and data relationships.
